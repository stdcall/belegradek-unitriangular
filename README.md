# Model Theory of Unitriangular Groups

O. V. Belegradek's article from *Model Theory and Applications*,
American Mathematical Society Translations, Series 2, volume 195 (1999),
pages 1–116, in a standalone edition.
[Original publication](https://doi.org/10.1090/trans2/195/01).

The article studies quasi-unitriangular groups, the correspondence
between rings and groups, elementary equivalence, spectrum functions,
and the undecidability of first-order theories.

The latest release contains the article and a separate list of
corrections. See [CONTRIBUTING.md](CONTRIBUTING.md) for build instructions.
